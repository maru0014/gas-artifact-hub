# ADR-005: Enterprise Hybrid デザインシステムと絵文字全廃・SVG採用

## ステータス
承認済み (Accepted)

## コンテキスト
初期のモック提案では、AI生成ツール特有の「サイバーネオングロー（紫・シアン発光）」「絵文字アイコン（⚡, 🚀, ✨, 🧮 等）の多用」「フローティング型コントロールバー」を採用していた。
しかし、利用者からのレビューおよび企業実務の視点において、以下の重要な課題が指摘された：
1. **「Geminiくさい」配色とチープ感**:
   派手なグラデーションや絵文字の多用は、一般企業の社内ポータルや業務ツールとして信頼感に欠け、導入ハードルとなる。
2. **フローティングバーと埋め込みツールのUI被り**:
   一般的なWebツール最上部のタイトルやナビゲーションボタンがフローティングバーで覆い隠され、操作できなくなる。
3. **社内管理台帳（リスト表示）の必要性**:
   カジュアルなカードグリッド表示だけでなく、情シスや管理者が安全スコアやバージョン、更新日を一覧・点検できるテーブル表示が不可欠。

## 検討した選択肢
- **案A: Option A（Modern App Hub / Linear風ダークモード固定）**
  - 洗練されているがダーク固定であり、保守的な業務環境では馴染みにくい。
- **案B: Option B（Workspace Canvas / Notion風シングルカラム）**
  - 上部に巨大なドロップゾーンがあり、ツール一覧の閲覧領域を圧迫する。
- **案C: Enterprise Hybrid 構成（採用）**
  - Option Aの「左サイドバー（探索・カテゴリ）」に、Option Bの「社内台帳テーブル切替」と「直感的なD&D・スキャンプレビュー」を統合。
  - 絵文字を全廃し、統一されたインラインSVGアイコンとInterフォントを採用。
  - ビューアは44pxのスリム固定ヘッダーでUI被りを完全解消。

## 決定事項
**案C（Enterprise Hybrid デザインシステム）を採用する。**
- 配色: スレートグレー（Slate 50〜900）＋ コーポレートブルー（`#2563eb`）。
- テーマ: ライトモード標準（デフォルト）＋ ダークモード切替トグル。
- アイコン: 絵文字全廃、線幅 `1.75px` のインラインSVGに統一。
- ビューア: 高さ44pxの固定スリムヘッダー、iframeは `height: calc(100vh - 44px)` で上下分割。

## 影響とトレードオフ
- **メリット**:
  - 企業の内製ポータルとして馴染みやすい配色・トーンを採用した（実際の導入先での評価は別途確認が必要）。
  - 44pxスリムヘッダーとiframeの上下分割により、ヘッダー起因のUI被りは設計上解消している。ただしツール側のコンテンツ自体が独自のフルスクリーンUIを持つ場合の被りまでは保証しない。
  - 一般社員（探索・起動）と管理者（台帳管理・安全性点検）の双方の利用を想定した画面構成にしている。
