# サブエージェントレビュー用プロンプトテンプレート集 (Prompt Templates)

本ドキュメントは、AIエージェントが独立した読み取り専用レビューへ依頼する際に使用する、目的別の標準プロンプトテンプレートを定義します。

---

## 1. UI/UX デザイン・モックレビュー用

```markdown
GAS Artifact Hub の画面デザイン（またはUIコンポーネント）において、以下のファイルを作成・更新しました：
- 対象ファイル: [ファイルパス]

以下の観点で厳密にレビューしてください：
1. 配色・トンマナ: Gemini/ChatGPT風のサイバーネオングローや派手なグラデーションが排され、日本企業・大手エンタープライズに自然に馴染むスレート＆コーポレートブルーになっているか？
2. アイコン規律: 絵文字が排除され、統一されたインラインSVGラインアイコンが使われているか？
3. ユーザー導線: 一般社員（探す・使う）と作成者（D&D共有・新バージョン更新）の双方が迷わない動線になっているか？
4. ビューアのUI被り: 44pxスリム固定ヘッダー等により、ツールの最上部UI（タブやボタン）を覆い隠していないか？
5. アクセシビリティ (WAI-ARIA): ⌘K/Ctrl+K検索、Escapeで閉じる、role="dialog", aria-modal="true", aria-label が実装されているか？

問題点や改善点があれば具体的にコードを示して指摘し、問題がなければLGTMを出してください。
```

## 2. セキュリティ・サンドボックス検証用

```markdown
GAS Artifact Hub のセキュリティ実装において、以下のファイルを作成・更新しました：
- 対象ファイル: [ファイルパス]

以下の観点で脆弱性や不備がないか厳格にレビューしてください：
1. サンドボックス隔離: iframe.srcdoc 注入により null origin が確実に強制されているか？ sandbox 属性に「allow-same-origin」が絶対に付与されていないか？ allow-popups, allow-scripts, allow-popups-to-escape-sandbox 等の必要最小限構成になっているか？
2. Stored XSS防止: ユーザー入力値やHTMLソースコードを表示する箇所で innerHTML が使われていないか？ textContent への代入や安全なエスケープが徹底されているか？
3. 静的スキャナー: 外部URL属性の単方向タグ走査と、他ルールの改行・空白を考慮した正規表現が、それぞれ回帰試験で確認されているか？
4. 同意バイパス防止: 初回同意キー（consentKey）がバージョン単位で分離され、v2.0更新時にConsent Bypassが起きないようになっているか？
5. 認可と排他制御: ロール判定（OWNER, EDITOR, VIEWER）でのメールアドレス小文字正規化、LockService による同時書き込み競合（Race Condition）対策が施されているか？

問題があれば厳密に指摘し、完全に対処されていればLGTMを出してください。
```

## 3. GAS バックエンドコードレビュー用

```markdown
GAS Artifact Hub のバックエンド処理（Google Apps Script）において、以下の変更を行いました：
- 対象ファイル: [ファイルパス]

以下の観点でレビューしてください：
1. GAS実行制限・クォータ考慮: 実行時間制限（6分）やDrive API呼び出し回数を考慮した設計になっているか？
2. 2階層ストレージと100KB制限: CacheService の100KB上限に対して90KB閾値による適切な分岐が行われているか？
3. トランザクション整合性・ロールバック: Drive先行保存後の失敗で補償を試行し、補償失敗時は `ROLLBACK_FAILED` と保持されたDriveファイルを手動復旧対象として扱うか？
4. コード構文・未定義変数: npm run check / npm test を通過し、GASランタイム（V8）で安全に動作するか？

問題点があれば行番号とともに具体的に指摘し、合格であればLGTMを出してください。
```
