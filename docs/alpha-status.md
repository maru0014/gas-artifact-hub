# アルファ版の検証状況

2026-09-06時点の開発側での検証結果です。本ソフトウェアは評価・検証を目的とするアルファ版です。本番導入・全社展開の受入完了を意味しません。導入先では[実環境受入試験計画書](acceptance.md)に従い、全24件を実測してください。同試験書の空欄は導入先が記入するためのものです。

## 実環境受入

Google Workspaceの同一管理者アカウントとChromeを用い、既存の専用検証環境とテンプレートから作った検証コピーで実施しました。いずれも同じ本番ソースを用い、デプロイ設定は `USER_DEPLOYING` / `DOMAIN` です。異なる実ユーザーでの検証は実施していません。

| 判定 | 対象 | 確認した範囲 |
| --- | --- | --- |
| PASS（13件） | A-1、B-1〜3、D-1〜5、E-1〜4 | 管理者本人表示、HTML投稿と台帳・Drive保存、1MB超過拒否、空タイトル拒否、カウンター動作、同意前のHTML未注入と同意後実行、親フレームアクセス遮断、ソース表示、CSV保存、個別・全体停止と再開、過去版への切戻し |
| 保留（10件） | A-2〜3、C-1〜8 | DB/Drive直接権限を持たない一般社員の本人識別と権限分離、公開範囲、編集権限、権限剥奪、管理責任者引継ぎ |
| 保留（1件） | A-4 | 外部アカウントのアクセス拒否 |

B-3は試験書の選択条件である空タイトルの拒否を実測しました。D-5は2行のCSVを1行へ絞り込み、保存されたCSVが期待内容と一致したことを確認しました。ブラウザ操作ツールのダウンロードイベント検知はタイムアウトしたため、保存成功の証拠は利用者が提示したChromeのダウンロード履歴と保存内容の確認です。

管理者による13件の成功は、別アカウントが必要な11件を代替しません。内部メールアドレス、ファイルID、デプロイURLを含む生の証跡は公開物に含めません。

## 追加で確認した範囲

- 実Sheetsで4台帳の物理行境界を越える追記と、管理責任者を除くACL200人の保存、タイトルのみの変更、201人の拒否後の状態不変を確認しました。旧APIなどを含むX-3全条件の完了ではありません。
- 実GASのScannerで未閉鎖タグ・長大タグ名を含む入力を単発測定し、80KBは12ms、256KBは32ms、1MBは49msでした。警告件数はいずれも0件です。この値はScanner内部処理だけの測定であり、HTML配信・画面表示時間、同時利用性能、SLAを示しません。
- 未初期化のテンプレートから同じ管理者が2コピーを初期化し、Spreadsheet・バインドScript・保存フォルダが独立すること、片方への投稿が他方へ混入しないことを確認しました。別会社・別ドメインでの導入を証明するものではありません。
- 本番ソースに対するローカル構文検査13ソース、単体テスト98件、Chromium E2E9件が成功しています。ローカル検証は実GASの認証・組織ポリシーを代替しません。

障害注入を含む補償の全条件、キャッシュ利用後の実ユーザーの権限失効、バックアップからの復旧、負荷・配信性能には未実測範囲があります。[追加試験](acceptance.md#4-追加の境界運用検証)と[性能検証手順](performance.md)を参照してください。

## テンプレートと公開状態

クリーンなSheet原本と独立コピーの検証は実施済みです。原本は未初期化のまま、リンクを知っている全員が閲覧・コピーできる設定で公開しています。[テンプレートをコピー](https://docs.google.com/spreadsheets/d/1lpmVMF7B3rP7x-V14Pg-5w0zm8gH5WALdWNKtkaAvNw/copy)から取得できます。

所有者とは別の個人Googleアカウントで、コピー画面の表示、Sheetのコピー作成、付属Apps Scriptのファイル一覧まで確認しました。この確認は配布導線だけを対象とし、コピーの初期化や個人Gmailでのアプリ運用は行っていません。外部アカウントのWebアプリ拒否試験（A-4）の代替ではありません。導入にはGoogle Workspaceが必要です。[配布用テンプレート作成手順](template-release.md)も参照してください。
