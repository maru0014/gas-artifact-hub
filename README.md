# GAS Artifact Hub

**アーティファクトを Google Apps Script（GAS）だけで安全に社内共有・版管理できるオープンソース・プラットフォーム。**

生成 AI 等で作成した単一 HTML アプリケーション（アーティファクト）を、Google Workspace 組織内で共有・実行・バージョン管理するための Web アプリケーションです。
追加の専用サーバーや外部クラウドを用意することなく、Google Apps Script（GAS）、Google スプレッドシート（設定・台帳・権限・監査）、Google Drive（HTML 実体ファイル）のみで安全に動作します。

> **アルファ版**:
> 2026-09-06時点で、管理者アカウントで実施できる実環境受入13件はPASSです。別の同一ドメインユーザーが必要な10件と外部アカウントによる拒否確認1件は保留です。複数ユーザーの本人識別・権限分離を含む本番受入は完了していません。
> 検証環境と結果の限界は [アルファ版の検証状況](docs/alpha-status.md) を参照してください。
> 企業や組織への本番導入を行う前に、必ず導入先の Google Workspace 実環境において [実環境受入試験計画書](docs/acceptance.md) に基づく検証を実施してください。
> ローカル自動テストは、Google の本人認証、組織ポリシー、実環境でのブラウザ挙動を保証しません。

## 主な機能（できること）

- **単一 HTML アーティファクトの登録**: ファイル選択またはドラッグ＆ドロップによるアップロード。
- **きめ細やかな公開範囲設定**:
  - **組織全体（all）**: ドメイン内の全員が閲覧可能。
  - **特定ユーザー（list）**: 指定したメンバー（編集者・閲覧者）のみアクセス可能。
  - **自分だけ（private）**: 管理責任者（custodian）のみが閲覧・編集可能。
- **バージョン管理と固定 URL**:
  - 新バージョンのアップロード、公開バージョンの切り替え、過去バージョンの保持。
  - バージョンを更新しても変わらない固定共有 URL（`?a=アーティファクトID`）。
- **ゼロトラスト隔離ビューア**:
  - `null` origin サンドボックスによる実行画面と、安全なプレーンテキストによるソースコード表示。
  - 静的スキャナーによる外部通信・動的実行の補助警告と、初回同意モーダル（Consent）。
- **ポータル管理機能**:
  - 全文検索、カード表示／台帳テーブル表示の切り替え、お気に入り登録、ダークモード対応。
  - スプレッドシートからの緊急停止（全体停止／個別停止）および管理責任者（custodian）の引継ぎ。

## 想定環境とシステム制約

| 項目 | 対応範囲と制約 |
| --- | --- |
| **対象組織・利用者** | 導入先と同一の Google Workspace ドメインで本人識別可能なユーザー |
| **実行基盤** | Google Apps Script（`USER_DEPLOYING` / `DOMAIN` デプロイ）＋ Google スプレッドシート ＋ Google ドライブ |
| **アーティファクト形式** | CSS・JavaScript をインラインに含む単一の UTF-8 HTML。標準サイズ上限 1MB（`MAX_HTML_SIZE_KB=1024`） |
| **非対応事項** | 個人 Gmail（`@gmail.com`）、社外アカウントへの共有、Google グループの展開、ZIP 等の複数ファイルアーカイブ、サーバーサイド処理 |
| **運用責任** | Google Workspace の契約、Drive 保存容量、GAS 実行クォータ（同時実行数・実行時間）、バックアップ、アップデートの管理が必要 |

### 【セキュリティに関する重要事項】
**サンドボックス環境は、任意のコードに対する完全な安全性を保証するものではありません。**
投稿された HTML は外部通信を行うことができ、利用者が入力したデータが外部へ送信されるリスクがあります。静的検査による「警告なし」は安全の証明ではありません。親フレームへのアクセスは遮断しますが、偽のログイン画面（フィッシング）、ブラウザリソースの過度な消費、悪意あるダウンロード等をサーバー側で完全に防ぐことは不可能です。詳細は [セキュリティポリシー](SECURITY.md) を必ずご確認ください。

## 導入クイックスタート

### Sheetテンプレートから始める

[GAS Artifact Hub のテンプレートをコピー](https://docs.google.com/spreadsheets/d/1lpmVMF7B3rP7x-V14Pg-5w0zm8gH5WALdWNKtkaAvNw/copy)

Google Workspaceの管理者アカウントで開いてコピーを作成してください。未初期化のSheetと本番Apps Scriptがコピーされます。コピーしたシートを開き直し、メニューの **GAS Artifact Hub → 初回セットアップ** から初期化してデプロイします（一時関数の追加・コード編集は不要です）。個人Gmailはアプリの運用対象外です。

### ソースを手動で配置する場合

1. 組織の管理者アカウントで新しい Google スプレッドシートを作成します。
2. スプレッドシートのメニューから **拡張機能 → Apps Script** を開き、`src/` 配下の全ファイル（13ファイル）と `appsscript.json` を配置します。
3. ソースを保存してスプレッドシートを再読み込みし、メニューの **GAS Artifact Hub → 初回セットアップ** を選択して初期化します（権限承認・保存先フォルダの指定または自動生成）。
4. セットアップ完了（5つの管理シート生成等）を確認後、Apps Script エディタの **デプロイ → 新しいデプロイ**（種類：ウェブアプリ）で、**次のユーザーとして実行：自分**、**アクセスできるユーザー：組織内の全員** を選択してデプロイします。
5. スプレッドシートや保存フォルダを直接共有していない一般社員のアカウントで、本人識別とアクセス権限を確認します。

詳細な手動配置手順および clasp を用いたセットアップ手順は [導入手順書](docs/setup.md) を参照してください。
配布用テンプレートの作成・確認手順は [配布用テンプレート作成手順](docs/template-release.md) にまとめています。

## 開発とテスト（コントリビューター向け）

本リポジトリの開発・検証には Node.js 22 以上を使用します。
なお、**一般利用者のブラウザおよび GAS 本番実行環境には Node.js や Playwright は一切不要**です。

```sh
# 依存関係のインストール
npm ci

# 本番コードの構文静的検査
npm run check

# GAS 互換ランタイムによる単体テスト（件数は実行結果で確認）
npm test

# 公開前チェック（不要ファイル・資格情報漏洩の検査）
npm run check:public

# ローカル E2E テストの実行（Playwright）
npx playwright install chromium
npm run test:e2e
```

### ディレクトリ構成
- `src/`: Google Apps Script にデプロイする本番ソースコード（`.gs`, `.html`）
- `tools/`: 本番コードを直接検証する単体テスト、構文検査、ローカル E2E スクリプト
- `examples/`: アーティファクトの仕様に適合したサンプル HTML
- `docs/`: 導入・運用・仕様・設計判断（ADR）などのドキュメント群
- `poc/03-fixed-url-version/`: 固定URL・キャッシュの独立シミュレータ（本番非配備。本番コードの検証とは別）
